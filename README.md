# Community Engagement Project

A web-based application aimed at increasing awareness and participation in various community-focused initiatives such as:

- Waste Management Techniques  
- Energy Conservation in Agriculture  
- Animal Husbandry and Poultry Farming  
- Rain Water Harvesting Techniques  

## Features

- Informational content presented in **three languages**: English, Hindi, and Marathi
- Built-in multilingual support using a custom `data-translate` system
- Simple and accessible HTML pages with inline translations
- Easy navigation for users to switch between languages dynamically

## Technologies Used

- HTML5  
- CSS3  
- JavaScript (for language switching)
